The call is the same `Reflect.apply` of the production `fromConfig`; the import changes from `captureAgentAdoption` to `../fromConfig.js`. Assertions unchanged. The migrated call passes `[input, new SettingsService(), {}, new CredentialAuthority()]`: `{}` is the fixture's own default intent and the other two satisfy the typed signature. No production defect: no host passes `undefined` for a required parameter. The T6.B14 Replaced test `refuses a non-Config before any credential acquisition from the supplied authority` (`config-initialization-boundary.behavior.test.ts`) covers the authority-credential expectation; it is not duplicated here.
