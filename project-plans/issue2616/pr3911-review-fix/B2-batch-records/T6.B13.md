## Decisions made while migrating

- Path B client index. `capturedSessionClient(owner)` returned the client the owner's conversation currently reaches. `ownerClients(owner)` lists the clients the factory returned in creation order: index 0 is the initial client and index 1 is the client created when `refreshAuth` runs during activation (`startChat()` on index 0 fails with "Content generator config not initialized"). The current client is index 1, so Path B reads `ownerClients(owner)[1]` (two reads per file: `startChat()` and the `driveReferenceLoop` argument).
- Path A harness seams. `createAgent` defaults `harness.forceInteractive`, `harness.forceConfirmations` and `harness.includeProcessCwd` to true. `forceConfirmations` injects an ASK-for-everything policy and the argument alias adapter (`confirmationForcing.ts`, `path` becomes `absolute_path`), so with defaults Path A read `package.json` successfully (one `tool-confirmation`, `isError: false`) while the CLI-style Path B correctly got `invalid_tool_params` (the fixture sends `path`), and `expect(pathA).toStrictEqual(pathB)` failed. The original Path A was the same hand-built Config as Path B (no forcing), and the CLI's production route (Route B) has no forcing either. Path A therefore passes the public `AgentConfig.harness` input as `{ forceInteractive: false, forceConfirmations: false, includeProcessCwd: false }` with `interactive: true` and `includeDirectories: [process.cwd()]` set explicitly, which reproduces the original Config. No assertion changed. If the orchestrator prefers that Path A keep the harness defaults, Path B's tool call would need the alias adapter too; that is a decision outside this batch.
- Environment and directory cleanup. The agent's `Config` is owned by `createAgent` and disposed by `agent.dispose()` (`withFixtureAgent`); the test restores `LLXPRT_FAKE_RESPONSES` and removes its working directory in its own `finally`.
- Path B hand-built acquisition kept as written (domain-level `SessionClientOwner`); only the factory source (`buildAgentClientFactory()`) and the client read changed.
