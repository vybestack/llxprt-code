## H-c change (orchestrator decision 1)

`helpers/gated-recording-mcp.ts` / `gated-recording-mcp-server.ts` gain, backward compatibly:

- option `gateDiscovery?: boolean` (default false; absent means the server's `tools/list` answers at once and writes no discovery line);
- methods `discoveryEntered(count = 1): Promise<void>` (resolves once the server has received `count` held `tools/list` requests, 30 s bound) and `releaseDiscovery(): Promise<void>`; both throw if the option was not set;
- effect line `{ event: 'discovery-entered' }`, written only when gated;
- the server takes the release file through the flag `--discovery-release=<file>`; positional arguments (effects file, tool name, optional call release file) are unchanged and flags are filtered out first.

Control test: `gated-recording-mcp.helper.behavior.test.ts` (3 tests: held until release then tool published; absent option answers at once with no discovery line; controls reject without the option).
