- Read needed: a session client whose `getCurrentSequenceModel()` returns a non-null value (`'gpt-4o'`, `'claude-x'`, any non-empty string), so that `agent.getCurrentSequenceModel()` can be shown to delegate to the agent's current client (T9d also: after a new session, the agent reads the fresh client, not the retired one).

The test works today only because `SequenceModelClient` overrides the method and is installed through `AgentConfig.runtimeFactoryBindings.agentClientFactory`.
- Rows tried (Observation rule): (a) public `Agent` API, no member sets or reports a sequence model other than `getCurrentSequenceModel` itself; real effects (a turn over the fake seam or a recording provider) never change the value, since production never assigns it. (b) production inputs: `AgentConfig.runtimeFactoryBindings.agentClientFactory` is not an observation input (wrapping or replacing the client factory is the capture moved to a public field and the field goes in T6.D2b); `contentGeneratorFactory`, `tokenizerFactory`, `credentialAuthority`, `toolSchedulerFactory` do not reach the client's sequence model. Writing `client['currentSequenceModel']` is a protected-field write, forbidden. (c) dropping an identity assertion does not apply: the delegated value itself is what the scenarios assert.
- Needs the orchestrator's decision, one of: Removed with the citation that production never assigns a non-null `currentSequenceModel` (`client.ts` lines 117, 287, 308, 312) so a non-null delegated value cannot occur, with T9b kept as the production contract (always `null`) and the delegation covered by a domain-level test of `projectCurrentSequenceModel` (already T9c); or Replaced by a domain-level test of `AgentClient`'s own reporting once something sets the value; or a `T6.Pk` that decides whether `currentSequenceModel` should ever be set (it looks like dead production state). The coder did not choose.

## Removed: T9a, T9d, PROP

Orchestrator decision: Removed. Proof:

- Production never assigns a non-null `currentSequenceModel`. In `packages/agents/src/core/client.ts` the field is declared at line 117 (`private currentSequenceModel: string | null = null;`) and assigned at lines 287, 308 and 312, all `this.currentSequenceModel = null`. Line 265 only reads it and line 757 returns it.
- The only way the old test produced a non-null value was a caller-supplied client through `runtimeFactoryBindings.agentClientFactory` returning a `SequenceModelClient` subclass. T6.D2b removes that field and the Observation rule forbids it as an observation input.
- So "the Agent returns a non-null sequence model the client reports" cannot happen in production. T9b (always `null` across repeated calls) and T9c (projection guards an absent client) stay Kept as the contract.
