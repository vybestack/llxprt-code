## H-e options added (this batch)

`openRouteBPreflight(options)` gains two optional inputs; behavior is identical when they are absent.

- `contributions?: ProviderContributionRegistry`: passed as the 5th argument of `prepareAgentPreflight` (use `createRecordingProvider(...).contributions` or any registry), so a provider other than `fake` can be selected. Set `config: { provider: <alias>, model: ... }` to match, and do not combine with the `fake` replay seam (it registers only `fake`).
- `proxy?: string`: passed as the host `proxy` field of `prepareAgentPreflight`'s first argument, the way a production host passes it (use `startLocalForwardProxy(...).url`).

The workspace owner construction moved into a local `openWorkspaceOwners(config)` to stay under the function-length lint limit; no behavior change.
