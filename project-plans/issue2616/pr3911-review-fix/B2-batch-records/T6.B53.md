## Unobservable reads

1. Scenario 2, `history.startCompression()` / `history.endCompression(summary, 2)` called by a producer that is not the facade.
   - Needs: the session client's `HistoryService`, and a compression whose `historyOrigin` is unset.
   - Rows tried: "Client calls that have an `Agent` equivalent" (`getAll/add/clear` only; no Agent member for `startCompression`/`endCompression`); "Listener or subscription counts (... compression flags ...)" (a domain-level test of the owner that subscribes: the subscriber here is the recording facade, which only the `Agent` builds, so there is no owner to construct with a test history); `Agent.sessionClient` and `AgentActivationOperation.sessionClient` expose no history; `Config` has no client accessor; the production compressions an agent runs (`Agent.compress`, `session-conversation-binding.ts:271`, `MessageStreamTerminalHandler.ts:86`) all pass the facade as `historyOrigin`.
   - Decision needed: Replaced by a named domain-level test (candidate: `packages/core/src/recording/RecordingIntegration.compressionBoundary.test.ts`, if it asserts that an origin-less `endCompression` summary reaches a recording subscriber), or Removed as unreachable in production if the orchestrator confirms no production caller of `performCompression` leaves `historyOrigin` unset (`CompressionHandler.ts:328, 442, 545` are internal retry paths not checked here).
2. Scenario 6, `history.replaceAll(..., { origin, afterPublication })`, `history.getAll()` identity and `history.getContentOrigin(...)`.
   - Needs: the session client's `HistoryService` and the `replaceAll` options (`origin`, `afterPublication`), which have no `Agent` form (`agent.setHistory` does not take `afterPublication`).
   - Rows tried: same as item 1; "Fault injected on the agent's client" (a real cause such as a failing journal write during `agent.setHistory` would change the scenario's stimulus and the `getContentOrigin` reads still have no public form); "Internal identity" (c) does not apply, because `getContentOrigin(summary) toBe(agent.session)` is the property under test, not a client identity.
   - Decision needed: (c) with a covering assertion the orchestrator names, or Replaced by a domain-level test of `HistoryService` (core) asserting that a rejected `replaceAll` keeps committed content and its origin, naming file and test.

The file keeps scenarios 2 and 6 on the old harness (`withRecordingLifetimeFixture`, `fixtureAgentResources`) so those two scenarios stay unchanged; they are the only remaining users of the old harness in this file. A follow-up `T6.B53b` finishes them after the decisions.
