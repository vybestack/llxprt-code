## Result

Startup dump configuration now resolves into one foreground session-scoped mode with precedence `session /dumpcontext` > explicit `--set dumpcontext=...` > `--dumponerror` > user-global `settings.json` > `off`. Explicit repeated `--set` entries use the last value. The active mode is inherited by subagents, and a later session command remains authoritative.

User-scope settings now expose `dumpcontext` (default `off`) and the P02 `dumpRetention` limits. Startup reads only `LoadedSettings.user.settings`, validates persistent modes and retention limits, and applies the values to the session runtime. Diagnostics reports the effective mode, including `off`. The `now` and `status` actions are rejected as persistent or `--set` values. Dead Config state/getters and the active `dumponerror` ephemeral registry entry were removed while legacy profile documents remain loadable and inert.
