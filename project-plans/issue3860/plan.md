# Issue 3860: Responses WebSocket lifetime recovery

Date: 2026-10-20. Branch: issue3860. Implementation only; parent owns final ROUND2 review, OCR, commits and remote operations.

## Scope and contracts

Retire Codex Responses connections at 55 minutes. A timer closes idle connections, defers active-stream retirement to the turn boundary, and is unreferenced and canceled on cleanup. Check wall-clock connection age again after acquiring the request turn to cover delayed timers. Rebuild connection-scoped requests with full history and no stale parent after retirement. Successful renewal stays on WebSocket and permits a new stateful chain.

Recover the exact documented status-400 invalid_request_error / websocket_connection_limit_reached envelope once. Classification remains based on the exact provider code, with no message matching. Preserve abort priority, request serialization, cleanup and the safety boundary against replaying exposed content or tool actions.

An attempt-local hidden prefix can be quarantined only for nonempty AI messages containing exclusively hidden thinking and no top-level metadata. Block-level encryptedContent and reasoning IDs are retained unchanged. Quarantine is bounded below 128 items and below 256 KiB of conservative retained-size estimates. Estimates include object/property overhead and three bytes per UTF-16 code unit, covering UTF-8 and UTF-16 storage without serializing a second copy. An individually oversized snapshot is published directly after the pending FIFO. Crossing either budget closes replay eligibility before the first yield. These limits apply to additional prefix retention; parser state and raw socket frame intake retain their existing behavior.

Every buffered publication and the following text/tool/metadata publication rechecks source failure. Publication state is set before yielding. Only an authorized lifecycle retry discards the prefix. Other non-abort failures publish the pending FIFO and then surface, preserving the wrapper's existing prohibition against HTTP fallback after content. Abort discards unexposed state immediately. A previously accepted successful terminal retains precedence over a later abort. Liveness callbacks continue while reasoning is quarantined.

Out of scope: HTTP retry policy changes, unrelated provider refactors, a live 60-minute endpoint soak, deployment, commits and remote changes.
