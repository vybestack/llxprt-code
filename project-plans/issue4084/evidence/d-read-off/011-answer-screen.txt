 Explaining TaskTool exports

   - `TaskToolParams` — the TypeScript interface for the tool’s input. It includes the subagent name and goal, optional behavior prompts

   - `TaskToolDependencies` — the interface for dependencies supplied when constructing the tool. It requires a child-launch function,
     task-policy and tool-governance readers, and a message bus. Tool registry, display callbacks, environment detection, and task-launch
     ownership are optional.
   - `TaskTool` — the class implementing the declarative task tool. It validates and normalizes parameters, then launches a subagent
     through the supplied dependencies. It supports foreground and async execution, optional child display callbacks, and streamed
     progress.
